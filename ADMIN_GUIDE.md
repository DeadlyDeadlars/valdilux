# Руководство по использованию админ-панели ValDiLux

## Доступ к админ-панели

1. Запустите backend сервер: `cd backend && npm run dev`
2. Откройте в браузере: `http://localhost:4000/admin`
3. Используйте учетные данные из `.env`:
   - Email: `admin@valdilux.ru`
   - Пароль: `admin123`

## Добавление товара

### Шаг 1: Загрузка изображений

Перед добавлением товара нужно загрузить изображения:

1. Используйте API endpoint для загрузки: `POST http://localhost:4000/api/upload`
2. Отправьте файл в поле `file` (multipart/form-data)
3. Сервер вернет путь к файлу: `{"url": "/uploads/1234567890-image.jpg"}`
4. Сохраните полученные пути - они понадобятся при создании товара

**Пример с curl:**
```bash
curl -X POST http://localhost:4000/api/upload \
  -F "file=@/path/to/your/image.jpg"
```

**Пример с JavaScript:**
```javascript
const formData = new FormData();
formData.append('file', imageFile);

const response = await fetch('http://localhost:4000/api/upload', {
  method: 'POST',
  body: formData,
});

const { url } = await response.json();
console.log('Uploaded:', url);
```

### Шаг 2: Создание товара в админ-панели

1. Войдите в админ-панель
2. Перейдите в раздел **Каталог → Товары**
3. Нажмите кнопку **Создать**
4. Заполните поля:

#### Обязательные поля:

- **name** - Название товара (например, "Стол Бостон двухтумбовый")
- **price** - Цена в рублях целым числом (например, 45000)
- **categoryId** - ID категории (1 - столы, 2 - шкафы, и т.д.)

#### Необязательные поля:

- **slug** - URL-адрес (генерируется автоматически из названия)
- **description** - Полное описание товара
- **material** - Материал (дуб/бук/ясень/сосна/берёза/комбинированный)
- **label** - Метка (hit/new/sale или оставить пустым)
- **inStock** - В наличии (true/false, по умолчанию true)

#### Изображения (images):

Вставьте JSON массив с путями к загруженным изображениям:
```json
["/uploads/1234567890-image1.jpg", "/uploads/1234567891-image2.jpg", "/uploads/1234567892-image3.jpg"]
```

**Важно:** Первое изображение в массиве будет использоваться как главное!

#### Опции товара (options):

Если товар имеет варианты (размеры, цвета), добавьте JSON конфигурацию:
```json
[
  {
    "name": "Размер",
    "values": [
      {"label": "Маленький (100x60)", "priceModifier": 0},
      {"label": "Средний (120x70)", "priceModifier": 5000},
      {"label": "Большой (140x80)", "priceModifier": 10000}
    ]
  },
  {
    "name": "Материал",
    "values": [
      {"label": "Дуб", "priceModifier": 0},
      {"label": "Ясень", "priceModifier": 3000}
    ]
  }
]
```

5. Нажмите **Сохранить**

## Управление категориями

1. Перейдите в **Каталог → Категории**
2. Нажмите **Создать**
3. Заполните:
   - **name** - Название категории
   - **slug** - URL (латиница, например "tables")
   - **image** - Путь к изображению категории (опционально)

## Управление заказами

1. Перейдите в **Заказы**
2. Просмотрите список заказов
3. Измените статус заказа:
   - Новый
   - В обработке
   - Оплачен
   - Отправлен
   - Доставлен
   - Отменён

## Управление отзывами

1. Перейдите в **Контент → Отзывы**
2. Просмотрите новые отзывы
3. Включите **approved** для публикации отзыва на сайте

## Управление контентом

### Посты (новости, статьи, акции)

1. Перейдите в **Контент → Посты**
2. Создайте новый пост:
   - **title** - Заголовок
   - **slug** - URL
   - **content** - Содержание (поддерживает markdown)
   - **type** - Тип (article/news/promo)
   - **image** - Изображение
   - **published** - Опубликовать (true/false)

### Купоны и промокоды

1. Перейдите в **Маркетинг → Купоны**
2. Создайте новый купон:
   - **code** - Промокод (например, "SALE2024")
   - **discount** - Размер скидки
   - **type** - Тип (percent - процент, fixed - фиксированная сумма)
   - **minAmount** - Минимальная сумма заказа
   - **active** - Активен (true/false)
   - **expiresAt** - Дата окончания (опционально)

## Просмотр заявок

1. Перейдите в **Заявки → ContactMessage**
2. Просмотрите сообщения от клиентов:
   - Обратные звонки
   - Вопросы по товарам
   - Обращения через форму контактов

## Советы

1. **Резервное копирование**: Регулярно копируйте файл `backend/prisma/dev.db`
2. **Изображения**: Используйте оптимизированные изображения (рекомендуется до 1MB на файл)
3. **Slug**: Используйте уникальные slug для товаров и категорий
4. **Цены**: Указывайте цены в копейках или рублях (целые числа)

## Автоматический импорт товаров

Если у вас много товаров, можно использовать скрипт для массового добавления:

```javascript
// backend/scripts/add-products.js
import { PrismaClient } from '@prisma/client';
const prisma = new PrismaClient();

const products = [
  {
    name: 'Стол Бостон двухтумбовый',
    slug: 'stol-boston-dvukhtumbovyy',
    description: 'Письменный стол из массива дуба...',
    price: 45000,
    material: 'oak',
    categoryId: 1,
    images: JSON.stringify(['/uploads/boston1.jpg', '/uploads/boston2.jpg']),
    inStock: true,
  },
  // ... другие товары
];

async function main() {
  for (const product of products) {
    await prisma.product.create({ data: product });
    console.log(`✓ Добавлен: ${product.name}`);
  }
}

main().then(() => prisma.$disconnect());
```

Запустите: `node backend/scripts/add-products.js`
