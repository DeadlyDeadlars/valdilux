## Рекомендации

1. **Добавить новые товары:** Если товары из списка "Папки без соответствующих товаров" должны быть в каталоге, добавьте для них записи в базу данных через админ-панель или создайте миграцию.

2. **Добавить главные фото:** Для папок без главного фото (Комод Бернард, КомодБар, и т.д.) рекомендуется переименовать одно из фото, добавив к названию слово "главная" или "главный", чтобы скрипт мог автоматически распознать его.

3. **Удалить тестовые данные:** Товары Monarch, Noble, Prestige, Executive и т.д. выглядят как тестовые и могут быть удалены из базы данных.

4. **Повторный запуск:** После добавления новых товаров или переименования фото, запустите скрипт снова для обновления данных.

## Созданные скрипты

Все скрипты находятся в папке `backend/scripts/`:

1. **sync-photos-and-reorder.js** - основной скрипт для синхронизации фото из Photo/ в public/photos/ и расстановки главных фото на первое место в базе данных
   
2. **check-main-photos.js** - скрипт для проверки наличия главных фото во всех папках
   
3. **show-unmatched.js** - скрипт для анализа несоответствий между товарами в базе и папками с фото

### Использование

```bash
cd backend

# Основной скрипт - синхронизация и переупорядочивание
node scripts/sync-photos-and-reorder.js

# Проверка главных фото
node scripts/check-main-photos.js

# Анализ несоответствий
node scripts/show-unmatched.js
```

## Техническая информация

**Критерии поиска главного фото:**
Скрипт ищет в названии файла следующие ключевые слова (регистр не важен):
- главная
- главный
- главное
- основная
- основной
- основное

**Алгоритм работы:**
1. Сканирование папки Photo/ и поиск всех подпапок с товарами
2. Копирование фото из подпапок в frontend-new/public/photos/
3. Сопоставление папок с товарами в базе данных по нормализованному имени (без пробелов, нижний регистр)
4. Для каждого товара:
   - Поиск главного фото по ключевым словам в названии
   - Формирование массива путей к фото
   - Перемещение главного фото на первую позицию
   - Обновление поля images в базе данных

**Безопасность:**
- Скрипт не удаляет существующие файлы
- Не перезаписывает файлы, если они уже существуют
- Проверяет изменения перед обновлением базы данных
- Выводит подробный лог всех операций
