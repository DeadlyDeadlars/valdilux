## Как запустить:

### Вариант 1: Быстрый запуск
```bash
cd frontend-new
npm run dev
```

### Вариант 2: С копированием медиафайлов
```bash
cd frontend-new
./start.sh
# Затем в новом терминале:
npm run dev
```

   ```bash
   npm install
   ```
